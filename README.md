# QRO TV DIGITAL

Plataforma audiovisual digital de Querétaro.

## Concepto

QRO TV DIGITAL integra una señal de transmisión continua, producciones bajo demanda, clips breves y contenido editorial en formato de revista digital.

## Módulos iniciales

- **Transmisión:** señal continua; el distintivo **EN VIVO** se mostrará sólo cuando el contenido se produzca en tiempo real.
- **Producciones:** catálogo de programas, series, temporadas y episodios.
- **Clips:** piezas audiovisuales breves.
- **Revista:** artículos y reportajes con acompañamiento visual y multimedia.

## Estado

Proyecto en configuración inicial como aplicación web progresiva (PWA).
